# Curated experiment evidence

This directory contains historical diagnostics, exploratory outputs, raw telemetry,
and curated evidence. The following files are the curated artifacts used for the
current project claims. Other files in this directory are retained for traceability
but should not be treated as primary evidence unless explicitly referenced by
`docs/CLAIMS_EVIDENCE.md`.

## Live active-trunk failover (Mininet + OVS + Ryu)

**Curated files**

- `2026-11-13_live_active_failover_trial_02.json`
- `2026-11-13_live_active_failover_trial_03.json`
- `2026-11-13_live_active_failover_trial_06.json`
- `2026-11-13_live_active_failover_trial_07.json`
- `2026-11-13_live_active_failover_trial_08.json`
- `2026-11-13_live_active_failover_summary.json`
- `2026-11-13_live_active_failover_summary.csv`

**Generation**

Each trial was generated by running the active-failover harness as root in the
isolated Mininet lab, with Ryu listening at `127.0.0.1:6653` and the controller
and OVS prerequisites ready:

```bash
sudo env NETOPS_FAILOVER_OBSERVATION_SECONDS=90 \
  NETOPS_FAILOVER_RESULT_PATH="$PWD/experiments/results/2026-11-13_live_active_failover_trial_XX.json" \
  PYTHONPATH=src:/usr/lib/python3/dist-packages \
  .venv/bin/python src/netops_guardrail/testbed/validate_active_failover.py
```

Replace `XX` with the trial number. The harness creates a fresh redundant
Mininet topology, verifies a clean baseline, administratively disables the active
trunk using OpenFlow 1.3 `ovs-ofctl mod-port ... down`, then observes STP
convergence and host reachability for 90 seconds. It writes the JSON event record
to the path supplied by `NETOPS_FAILOVER_RESULT_PATH`.

The selected five passing records were consolidated with:

```bash
python experiments/summarize_failover_results.py
```

The five selected trials and summary record their source harness commit as
`c6831e2a86da7fccb81b9c03c9ffed3ad7144135`. The records were later committed
to this repository in commit `3d2148ca5cf61186b3bad53368b2c3cc25f70252`.

**Interpretation limits:** this is an emulated Mininet/OVS/Ryu test, not a
physical cable-pull test. Fault injection is an OpenFlow administrative port-down.
It demonstrates STP alternate-path failover, not AI-driven remediation or a
production SLA. Five trials are a small sample.

## Qwen structured-output evaluation

**Curated files**

- `2026-11-10_qwen_structured_full.json` — full 30-scenario run.
- `2026-11-10_qwen_structured_full.csv` — row-level export of that run.

The one-scenario smoke artifacts
(`2026-11-10_qwen_structured_smoke.json` and
`2026-11-10_qwen_structured_smoke.csv`) are retained as setup/debug evidence,
not as the primary evaluation result.

**Generation**

With the Ollama service running and the `qwen2.5-coder:1.5b` model available:

```bash
PYTHONPATH=src .venv/bin/python \
  src/netops_guardrail/experiments/evaluate_llm_scenarios.py \
  --model qwen2.5-coder:1.5b \
  --output experiments/results/2026-11-10_qwen_structured_full.json
```

The evaluator reads the frozen labelled fixture
`2026-10-30_2541695_llm_scenarios_labeled.json`, calls the local Ollama
generation API in JSON mode, validates the raw response and intent schema, and
passes each effective intent to the independent guardrail. It writes both JSON
and CSV outputs. The full run metadata records source commit
`c6831e2a86da7fccb81b9c03c9ffed3ad7144135`; the artifacts were committed in
`3d2148ca5cf61186b3bad53368b2c3cc25f70252`.

**Interpretation limits:** these are 30 deterministic synthetic scenarios, not
a general model-accuracy benchmark and not a live OVS evaluation. The result
supports only the recorded JSON/schema and guardrail outcomes for this fixture.

## Provenance conventions

- Each JSON artifact's `metadata` records its generation date, command, and
  source commit where the harness records them.
- The generation commit is not necessarily the commit that later adds the
  evidence file to Git; both are identified above.
- Do not edit curated result files manually. Re-run the documented harness and
  preserve the raw output if a result needs to be refreshed.
